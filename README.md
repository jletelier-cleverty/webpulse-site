# WebPulse

Landing page para WebPulse - agencia de diseno web profesional.

## Stack

- HTML + Tailwind CSS (CDN)
- Google Fonts (Space Grotesk, Inter)
- Vanilla JS (particle network, scroll animations, counters)

## Deploy

Cloudflare Pages apuntando a `/public`.
